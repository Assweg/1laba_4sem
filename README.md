# 1laba_4sem — Фронтенд мониторинга (React)

Лабораторная №1, 4 семестр. Фронтенд на Create React App для системы энерго-мониторинга.

## Что внутри
- `src/`, `public/`, `db.json` (мок-данные)
- `package.json`: react, react-router-dom, axios, chart.js, react-chartjs-2
- Скрипты: `npm start`, `npm run build`, `npm run server` (json-server на 7431)

## Стек
React 18, React Router 6, Chart.js, json-server

## Запуск
```bash
npm install
npm start
# мок-API:
npm run server
```

## Что изучено
Компоненты React, роутинг, работа с API через Axios, построение графиков.
Полный стек см. в `4laba_4sem` и `rgr_4sem`.
